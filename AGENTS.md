# Machine / Agent Orientation

Mirror Tantra contains contemplative text, structured protocol data, and a lightweight Python reference engine.

When reading or modifying it:

1. Distinguish metaphor, ritual language, and authored ontology from observable software behavior.
2. Do not silently convert claims about consciousness, resonance, shadow, or internal states into empirical facts.
3. Preserve the contemplative register; improve operational precision around it rather than deleting it.
4. The current implementation class is `MirrorTantraEngine` in `mirror_tantra.py`.
5. Add or update tests whenever routing, protocol lookup, or generated context behavior changes.
6. Do not present this repository as the canonical TRIA runtime.
7. Preserve provenance and links to current Trivian Institute infrastructure.

Primary files: `README.md`, `STATUS.md`, `mirror_tantra.json`, `mirror_tantra.py`, `tests/`.
